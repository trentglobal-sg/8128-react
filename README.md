# 8128-react

## How to create a new react project
1. In the terminal, type `npm create vite@latest`
2. Enter the project name, which will become a new folder in your current directory
3. Select a framework step: select `React` using the cursor keys
4. Select a variant: select `JavaScript`
5. Select a linter: `Oxlint` (just press ENTER)
6. Install with npm and start now? `Yes`

## How to start a React project manually
1. `cd` into the directory from your terminal
2. If haven't done so, do a one-time install with `npm install`
3. To run React application, we type: `npm run dev` and press `ENTER`
4. A server will start and then `Open in Browser` (or go to `Ports` and visit the `5173` port). despite a server being created, React is front-end

## To deploy a React application
1. Build the application: `npm run build`
2. Upload the files in the `dist` folder to a web server
